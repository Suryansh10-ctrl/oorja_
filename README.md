# OORJA 2026 — College Fest Website

A modern, interactive and responsive website for **OORJA 2026**, a college fest focused on music, culture, competitions, creativity, and celebration.

Built with **React, Vite, Tailwind CSS, and JavaScript**, featuring event listings, team information, gallery, night-wise lineup, countdown, responsive navigation, animations, filters, modals, and interactive UI components.

### Tech Stack

* React
* Vite
* Tailwind CSS
* JavaScript
* React Router
* Lucide Icons

### Features

* 🎉 OORJA 2026 landing page
* 🎵 Night-wise event/lineup section
* 🎯 Event categories and filtering
* 👥 Team section
* 🖼️ Interactive gallery
* ⏳ Live countdown
* 📱 Fully responsive design
* ✨ Scroll and entrance animations
* 🎫 Pass/ticket interactions
* 📋 Contact and FAQ sections
* 🌙 Modern festival-inspired visual design

**OORJA 2026 — Where Energy Meets Celebration.**
